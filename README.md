# Nolia Website

Official website for Nolia, a local-first Markdown knowledge workstation.

## Development

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

The production output is generated in `dist/`.

## Deployment

This repository includes a GitHub Pages workflow at `.github/workflows/deploy.yml`.
After pushing to GitHub, enable Pages for the repository and select GitHub Actions
as the build and deployment source.

## Release Links

Download links currently point to a placeholder GitHub Releases URL:

```text
https://github.com/your-org/nolia/releases/latest
```

Update `githubReleaseUrl` in `src/App.tsx` when the final release repository is ready.
